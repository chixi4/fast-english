## 差异根因归纳
- 第一类是稳定的视觉差异。网页长期处于深色主题，同时被 Via 浏览器地址栏和底部工具栏包裹，导致可视区域和安卓原生界面不一致。
- 第二类是数据状态差异。网页词库和学习统计多为零值，安卓基准图是有真实学习记录的状态。
- 第三类是流程错位。多个编号截图采样时没有停在目标功能界面，而是停在加载页、学习页或浏览器主页。
- 第四类是关键功能未拍到目标动作态。典型集中在查词详情链路、提前复习弹窗链路、学习数据页链路、今日新词链路和实验室弹窗链路。
