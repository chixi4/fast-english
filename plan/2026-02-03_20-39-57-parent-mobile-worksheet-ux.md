# Plan: 家长模式手机端 UI 修复 + 试卷重排版

## 🎯 任务概述
目标：把家长模式在手机端的所有可见问题一次性扫干净，重点把“试卷/打印”做到**不溢出、少翻页、像正规试卷、好批改**，并把交互流程继续压缩到“每天 3 分钟”。

本计划基于双模型至少三轮评估产出（全链路 → 逐页/试卷 → 文案/细节），对齐记录见：
- `docs/parent_mode/AI_MOBILE_UX_REVIEW_2026-02-03_R1.md:1`
- `docs/parent_mode/AI_MOBILE_UX_REVIEW_2026-02-03_R2.md:1`
- `docs/parent_mode/AI_MOBILE_UX_REVIEW_2026-02-03_R3.md:1`

## 🧠 当前共识（从三轮评估提炼）
1. **手机端预览不应横向溢出**：现在 `.worksheet-table` 不吃手机端的表格滚动规则（只对 `.table` 生效），是 P0。
2. **打印分页不应强制每题型一页**：`.worksheet-break` 当前强制分页，浪费纸且影响观感，是 P0。
3. **家长批改必须更省力**：答案视图/批改视图应更“对答案友好”，错题录入不应费眼找词。
4. **去 AI 味文案**：减少“教育用户”的重复句，按钮/提示更短、更像真实产品。
5. **下拉/选择器要可滚动**：deck-picker 在手机上可能被裁切或超出屏幕，需加 max-height/滚动或改为原生选择器。

## 📋 执行计划

### Phase 1：建立手机端 Bug 清单与回归基线（半天）
1. 建立“手机端检查清单”（按页面）：`/`、`/worksheets`、`/worksheets/{id}`、`/settings`、`/library`、`/decks`。
2. 统一验证尺寸：320px / 375px / 390px / 430px（竖屏），并记录“溢出/遮挡/不可点/滚动异常/字体过小”。
3. 明确试卷两种需求：**手机预览可读** 与 **A4 打印好写**（优先保证打印）。

### Phase 2：移动端布局 P0 修复（1 天）
4. 修复试卷表格在手机端溢出（屏幕视图）：  
   - 方案：`@media screen and (max-width: 640px)` 下把 `.worksheet-table` 做成“列表/卡片”视图（不横向滚动）。  
   - 打印视图保持表格，并加 `table-layout: fixed` + `word-break` 防止长词/长释义撑爆。
5. 修复选择题选项拥挤：手机端 `.worksheet-q-choices` 强制单列；打印端保持双列或按“省纸/标准”切换。
6. 修复 deck-picker 手机端“超出屏幕/无法滚动”：`.deck-picker-menu` 增加 `max-height: 50vh; overflow-y: auto; -webkit-overflow-scrolling: touch;`；必要时改为原生 `<select>`（移动端优先）。
7. 修复输入与选择热区：  
   - `/worksheets` 的 textarea 增加最小高度（键盘弹出仍可编辑/检查）。  
   - 提取结果与错题勾选：整行可点、选中态更明显、行高 ≥ 44px。

### Phase 3：试卷内容与打印排版重做（1 天）
8. 试卷提供两种打印布局（优先 P0 做“省纸版”，标准版作为 P1）：  
   - 省纸版：不强制分页，靠浏览器自然分页 + `break-inside: avoid` 保证题块不被截断。  
   - 标准版：按大题分页（可选），更像学校试卷（姓名/日期/得分/用时/签字栏）。
9. 调整题目内容让“更像真实作业”：  
   - 试卷头：姓名/日期/用时/得分/家长签字。  
   - 拼写题：可选“提示首字母”（默认关，给低年级用）。  
   - 填空题：限制句长；词库在纸面上更就近（避免翻页找词）。

### Phase 4：文案去 AI 味 + 交互再精简（半天）
10. 全面替换高频文案（按钮/提示/区块标题），目标：短、像真实产品、少解释后台逻辑。  
    - 把“安排复习/算法/权重”等词收起，用“已记录错题/明天会再出现/记忆进度”表达。
11. 交互进一步压缩：  
    - 生成→打印：主入口更聚焦（减少“两个主按钮并列”的纠结）。  
    - 批改→录入：考虑增加“批改模式/纯答案视图”，减少滑动对照成本。

### Phase 5：验收与回归（半天）
12. 按验收清单逐条验证（含 iPhone SE 宽度的极限情况 + 打印预览）：  
    - 手机端：试卷不横向溢出；下拉可滚动；按钮不换行或不抖动；键盘不遮挡关键按钮。  
    - 打印端：不再强制每大题一页（省纸）；内容不被裁切；下划线清晰；题目不被拦腰截断。

## ✅ P0 验收标准（可演示）
1. 手机（375px 宽）打开 `试卷页`：无横向滚动条；三题型都能顺畅纵向浏览。
2. 手机端选择题选项单列，文字不挤、不乱。
3. `deck-picker` 词书多时仍可滚动选择，不会超出屏幕导致点不到。
4. 打印预览（A4）：不再强制每大题一页；15 词“省纸版”尽量 1 页或接近 1 页；不裁切。
5. 文案不再出现明显技术词或重复“孩子不接触屏幕”的教育式语句。

## ⚠️ 风险与注意事项
- “手机预览”和“A4 打印”存在冲突：必须明确哪一个是主体验（建议：打印优先、手机预览不崩即可）。
- “省纸版”若过度紧凑，会降低低年级可写性；需要给出可选的大字/标准布局。
- 选择器改造（deck-picker）涉及交互一致性：移动端优先保证可用性，必要时牺牲视觉统一。
