# Plan: 家长向背单词 MVP（生词提取 + 纸质作业）

## 🎯 任务概述
把现有“背单词+复习+错词强化”的底座，切换为“家长要控制感/不盯屏幕”的产品主线：从真实文本提取生词→生成定制词单→打印作业→录入错题→复习安排。

## 📋 执行计划
1. Go/NoGo：把家长需求压缩为一个可演示闭环，定义 P0 验收（3 分钟跑通）与不做清单。
2. 边界与包装：决定家长模式在现有产品内落地；调整导航与文案，AI 功能收纳到“练习/高级”。
3. 数据资产：明确生词提取排除规则、默认词书与演示样本文本；准备“额外几百词”的词书方案。
4. P0-生词提取：粘贴文本→提取候选→可编辑→一键生成 Deck 并可选加入学习计划。
5. P0-纸质作业：从“今日/Deck”生成可打印作业页（HTML Print），并提供“录入错题”回流到 Mistake/SRS。
6. AI（可选增强）：例句/题目生成走 UI 参数化；writer 用快模型，checker 用思考模型做校验与修正。
7. UI/打印定稿：补齐打印样式与演示脚本，保证跨浏览器可用性。
8. 走查与反馈：录屏给老师/家长评审，调整默认参数与题型。
9. 交工：演示稿、路线图、维护成本与反馈机制（数据飞轮）。

## ⚠️ 风险与注意事项
- 生词提取准确性与可解释性优先（可让家长看到“为什么算生词”）。
- 打印体验要稳定（分页、字号、留白、答题区）。
- AI 接入要有 Mock/降级方案，避免演示被 Key/网关影响。

## ✅ P0 验收清单（3 分钟演示）
1. 打开 `http://127.0.0.1:8000/library` 导入 `中考词汇（ECDICT）` 与 `高频 10k（arstgit）`
2. 打开 `http://127.0.0.1:8000/settings` 完成一次“家长模式”设置（阶段/每日词量/目标词库/词频）
3. 打开 `http://127.0.0.1:8000/worksheets` 粘贴一段英文文本 → 提取生词
4. 看到生词被自动标注（课本内/目标/高频）且默认已预勾选推荐词
5. 一键生成作业（3 题型）并点击打印（打印自动隐藏导航与答案）
6. 家长在网页端勾选错词并提交 → 系统记录 Mistake + FSRS 排程（下一次“今日作业”可复用）
