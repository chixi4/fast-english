# Plan: 家长向背单词 MVP（生词提取 + 纸质作业）

## 🎯 任务概述
把现有“背单词+复习+错词强化”的底座，切换为“家长要控制感/不盯屏幕”的产品主线：从真实文本提取生词→生成定制词单→打印作业→录入错题→复习安排。

## 📋 执行计划
1. Go/NoGo：把家长需求压缩为一个可演示闭环，定义 P0 验收（3 分钟跑通）与不做清单。
2. 边界与包装：决定家长模式在现有产品内落地；调整导航与文案，AI 功能收纳到“练习/高级”。
3. 数据资产：明确生词提取排除规则、默认词书与演示样本文本；准备“额外几百词”的词书方案。
4. P0-生词提取：粘贴文本→提取候选→可编辑→一键生成 Deck 并可选加入学习计划。
5. P0-纸质作业：从“今日/Deck”生成可打印作业页（HTML Print），并提供“录入错题”回流到 Mistake/SRS。
6. AI（可选增强）：例句/题目生成走 UI 参数化；writer 用快模型，checker 用思考模型做校验与修正。
7. UI/打印定稿：补齐打印样式与演示脚本，保证跨浏览器可用性。
8. 走查与反馈：录屏给老师/家长评审，调整默认参数与题型。
9. 交工：演示稿、路线图、维护成本与反馈机制（数据飞轮）。

## ⚠️ 风险与注意事项
- 生词提取准确性与可解释性优先（可让家长看到“为什么算生词”）。
- 打印体验要稳定（分页、字号、留白、答题区）。
- AI 接入要有 Mock/降级方案，避免演示被 Key/网关影响。

# Plan（续）：家长模式与旧功能的融合改造（按 3-Day 方法）

## ✅ 已完成的对齐与发现（用于后续执行）
- 双模型对齐（融合形态/信息架构）：`docs/parent_mode/AI_ALIGNMENT_2026-02-03_integration.md`
- 真实用例跑通与关键发现：
  - 当前导航同时暴露“开始学习/应语/错词篮”等屏幕学习入口，家长会困惑且不符合“孩子零屏幕”约束。
  - “一键生成今日作业”存在时序/口径问题：有时提示“没有到期单词可生成作业”，但回到首页又能看到待学数量增加（说明补新词已发生，但本次生成没捞到或提示误导）。

## 🎯 融合目标（P0）
把“家长纸质作业闭环”升级为默认主线：家长打开首页就只有一条明确主路径（生成今日作业→打印→勾错题→自动进入下次复习），旧的屏幕学习能力保留但收纳到“高级/更多”，避免干扰。

## 📋 3-Day 执行计划（面向下一轮迭代）

### Day 1：边界 & 形态定稿（决策做早）
1. **定稿融合形态（建议：A + C-lite）**  
   - A：把 `/`（今日）改造为“今日作业”主入口（主按钮=生成/打印）。  
   - C-lite：增加“纸质作业模式开关”（开启后导航/首页/入口都切到家长视角，屏幕学习入口隐藏到高级）。  
2. **词表选择降负担（3 词表心智）**  
   - 课本词表（可选，用于“课本内/外”标注）  
   - 考试目标词表（可选，如中考/小升初/KET）  
   - 课外高频词表（可选，用于排序与推荐）  
   规则：没选也能跑（系统推荐默认值/自动兜底）。  
3. **统一口径：待学/到期/今日作业**  
   - 明确“今日作业词”来源优先级：错题 > 到期复习 > 自动补新词（直到每日词量）。  
   - 统一 toast 文案：今日无到期时应提示“今日已完成/可从文本生成新作业”，避免误导“先导入词书并加入学习计划”。  
4. **更新 P0 验收脚本（3 分钟）**  
   - 登录后首页无“开始学习”，只有“生成今日作业/从文本提取”等家长动作。  

### Day 2：实现融合（MVP 可运行）
1. **实现“纸质作业模式开关”与导航裁剪**  
   - 开启后：导航仅保留（今日作业/词书/设置）（是否保留“错题本”按 UI 决策）。  
   - 关闭后：保留原自学导航与闪卡学习。  
2. **修复“今日作业”生成口径问题（确保 100% 可出题）**  
   - 生成时先查到期复习；不足则补新词并保证本次生成能捞到新增卡（避免“补了但本次为空”）。  
   - 无词时给出正确指引（导入词书/从文本提取/调整每日词量）。  
3. **把错题回流做成“就地闭环”**  
   - 作业详情页提交错题后，直接给出“明日会自动出现”的确认与返回入口。  
   - 生成逻辑确保错题在下一张作业中优先出现（无需用户理解错词篮/复习算法）。  
4. **打印体验 P0 定稿**  
   - 增加“大字版/低年级版”打印样式开关（不暴露复杂字号设置）。  
   - 确保打印隐藏导航/答案/录入区，分页、留白、答题区稳定。  

### Day 3：演示走查 & 反馈闭环
1. **录屏给家长/老师评审**：同一份演示脚本跑 2-3 次，收集“卡点/误解点”。  
2. **根据反馈微调默认值与文案**（优先修“误导与选择困难”，不做大重构）。  
3. **列路线图**：KET/小升初词表导入方案（由用户提供词表/合规来源）、作业模板扩展、错题周复习等。  

## ⚠️ 风险与阻塞（需要持续关注）
- 家长模式与自学模式共存时，入口收纳不当会导致“功能消失”的抱怨（需要清晰开关与说明）。
- 自动补新词的量如果波动，会造成“今天怎么这么多/怎么这么少”的不稳定体验（需要固定的每日词量口径）。
- 打印在不同浏览器/打印机上排版差异，需要至少覆盖 Chrome/Edge（Windows）+ Safari（如有）。
