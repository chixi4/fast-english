# 词书来源与许可说明

本项目内置的词书来源分两类：

1. **ECDICT 标签词书（MIT）**：直接从开源词典 ECDICT 的 `tag` 字段筛选生成，天然带释义与音标信息。
2. **高频派生词书（MIT 派生，非官方）**：从开源高频词表抽取前 N 个词，再用 ECDICT 补全释义。用于“快速上手/家长场景”，**不是任何考试官方发布的原始词表**。

> 入口：网页「词书库」`/library` → 选择词书 → 点击「导入」。

---

## 一、ECDICT 标签词书（MIT）

来源：
- 项目：skywind3000/ECDICT
- 主页：`https://github.com/skywind3000/ECDICT`
- 许可：MIT

内置示例（以实际页面为准）：
- 中考词汇（ECDICT）：`tag=zk`
- 高考词汇（ECDICT）：`tag=gk`
- 四级/六级（ECDICT）：`tag=cet4/cet6`
- 考研（ECDICT）：`tag=ky`
- IELTS/TOEFL/GRE（ECDICT）：`tag=ielts/toefl/gre`

特点：
- 优点：有较完整的释义/音标信息，适合生成「英译中」等依赖释义的题型。
- 注意：词表规模较大时，首次导入会花一些时间（需要下载/解析数据）。

---

## 二、高频派生词书（MIT 派生，非官方建议）

来源：
- 高频词表项目：arstgit/high-frequency-vocabulary
- 主页：`https://github.com/arstgit/high-frequency-vocabulary`
- 许可：MIT

派生方式：
- 从高频词表抽取前 N 个词（例如 Top 1200/2000/3500）
- 使用 ECDICT 补全释义（若某词在 ECDICT 中缺失，则该词会缺少释义）

内置示例（以实际页面为准）：
- 小学核心词汇（高频精选 1200）
- 小升初/初中基础（高频精选 2000）
- KET 词汇（高频建议 1800）
- PET 词汇（高频建议 3500）

适用建议：
- **家长模式**：优先导入「小学核心/小升初」作为目标词库；再配一个「高频 10k」作为词频参考。
- **需要更“贴合学校教材”**：建议你额外导入课本词表（可从教材配套资料或学校发的词表整理后导入），并在「家长模式设置」里选为“课本词表”。

---

## 三、自定义导入（推荐用于课本词表 / 机构词表）

入口：
- 「单词库」`/words` → 在页面中粘贴/上传导入
- 或直接使用「词书库」导入后，再用「单词库」补充

支持格式：
- **一行一个单词**：只填 `term`（释义/例句可后续补）
- **CSV/TSV**：推荐列：`term,definition,example,tags,deck,chapter,position`

导入小技巧：
- 你可以在导入文本开头加元信息（以 `#` 开头），例如：
  - `# deck: 七年级上册`
  - `# tags: textbook, grade7`
  - `# separator: tab`

注意：
- 如果导入的词缺少中文释义，家长作业会自动降级题型（移除「英译中」选择题），以保证纸质作业可用。
