# 家长模式（纸质作业）MVP 使用说明

目标用户：小学/初中家长（孩子**完全不接触屏幕**），家长用网页生成纸质作业并录入错题，让系统自动安排下次复习。

## 1. 准备词表（一次性）

**推荐（最低认知负担）**
1) 打开 `http://127.0.0.1:8000/library`
2) 先导入：
   - `中考词汇（ECDICT）`（用于“常考/值得学”判断与词库覆盖）
   - `高频 10k（arstgit）`（用于“高频优先”与排名提示）

**可选：导入课本词表（用于区分课本内/外）**
- 把孩子当前教材词表导入到一个单独的词书（建议命名：`课本词表`）
- 导入入口：
  - `http://127.0.0.1:8000/words` 批量导入（可带 `#deck:`）
  - 或把词表做成 CSV/TSV 每行一个词

> 说明：项目不会内置 KET/小升初官方词表（版权不确定）。如果你有自己的 KET/小升初词表，也建议导入成单独词书，然后在“家长模式设置”里勾选为“目标词库”。

## 2. 家长模式设置（一次性）

打开 `http://127.0.0.1:8000/settings` → **家长模式**：
- **孩子阶段**：小学 / 初中
- **每日推荐词量**：默认 10（可按孩子承受能力调整）
- （可选）课本词表：选择你导入的 `课本词表`
- （可选）词频词表：选择 `高频 10k（arstgit）`
- （可选）目标词库：勾选 `中考词汇（ECDICT）`、你自己导入的 `KET/小升初` 等

## 3. 每日使用（两种方式）

入口：`http://127.0.0.1:8000/worksheets`

### 方式 A：从文本提取生词（推荐）
1) 粘贴绘本/阅读材料/台词
2) 点击 **提取生词**
3) 系统会自动标注并预勾选更推荐的词（按“目标词库/高频/课本内外”综合）
4) 点击 **生成可打印作业（3题型）**
5) 点击 **打印**

### 方式 B：一键生成今日作业（按复习安排）
不粘贴文本，直接点 **一键生成今日作业**：
- 从到期复习里挑词
- 不足时会自动补充新词（优先目标词库，其次学习计划词书，再其次任意词书）

## 4. 作业题型（固定 3 种）
1) **看中文写英文（拼写）**
2) **英译中选择题**
3) **语境填空（词库填入）**

> 作业页会提供“答案（仅网页显示）”，打印时自动隐藏，避免孩子看到。

## 5. 录入错题（形成闭环）
孩子做完后，家长打开作业页面底部：
- 勾选“这次不会/拼错”的单词
- 点击 **提交并安排复习**

系统会把：
- 勾选的词记为 `Again`（并写入错词记录）
- 未勾选的词记为 `Good`

下次生成作业时会根据 FSRS 复习安排自动出现。
